## 1\. 新增无牌车二维码生成
### 1\.1 业务逻辑
    当业务人员对云之家群中@机器人发送含有"无"字的车牌时，需要根据下面的规则生成二维码，并返回，除开新增的二维码以外，其他的内容信息不变
### 1\.2 编码规则 

1. 原始内容拼接公式：

    ```Plain Text
    二维码原始明文 = {ShopId} + "__" + {Id} + "__" + {Info}
    ```

    - `ShopId`：供应商接口返回的门店 ID \(数字类型\)

    - `Id`：供应商接口返回的出门单唯一 ID \(数字类型\)

    - `Info`：供应商接口返回的车牌号 \(字符串类型\)

2. 对原始明文执行**标准 UTF\-8 编码**

3. 执行**标准 Base64 编码**得到`Code`字段 \(仅用于校验，不对外返回\)

### 1\.2 二维码渲染参数 \(逻辑由AI生成，可以调整\)

|参数|取值|说明|
|---|---|---|
|版本|自动适配 \(version=1\)|仅存储 3 个主键，最小版本即可容纳|
|纠错级别|ERROR\_CORRECT\_M\(15%\)|平衡扫码容错率和图片大小|
|模块大小 \(box\_size\)|6 像素|适配 58mm 热敏纸和手机扫码，低于 4px 会导致扫码失败|
|边距 \(border\)|2 模块|符合二维码标准，小于 2 会影响边缘识别|
|颜色模式|纯黑白二值图<br>|禁用灰度 / 彩色，大幅减小文件体积|

### 1\.3 校验标准

生成的二维码用任意扫码工具识别，结果必须与上述原始明文完全一致。

## 2\. 最小化存储 PNG 生成方案

### 2\.1 标准模板布局 \(从上到下\)

1. 居中标题：`出门单 {No}`

2. 门店名称：`{company_name}`\(完成注册后的机器人[公司名称]\)

3. 车牌号码：`车牌号码: {Info}`

4. 发放时间：`发放时间: {StartTime}`

5. 放行原因：`放行原因: {Service}`

6. 1 像素黑色分割线

7. 居中提示：`出门请扫描下方二维码`

8. 居中二维码 \(200×200 像素\)

9. 备注 \(非空时显示\)：`备注: {Desc}`

10. 居中页脚：`谢谢惠顾，欢迎再次光临！`
